# Laravel Game Template

Основное приложение Laravel находится в корне, Phaser и игровой Vue-интерфейс —
в `game/`, сайт Inertia — в `resources/`. Игровые файлы раздаются статически из
`public/game-assets/`. Версионированный публичный API удалён; браузер использует
защищённые web-маршруты `/internal/*`. Подписанные платёжные вебхуки сохранены.

Установка, команды разработки, сборки и тестирования приведены в
[README](README.md). Нужны PHP 8.4.1+, Node 22.13+ и Composer 2. На Windows при
ограничении PowerShell используйте `npm.cmd`, не меняя системную политику.

Подробный [отчёт о переносе](docs/architecture/LARAVEL_FIRST_RESTRUCTURE.md)
содержит карту зависимостей и маршрутов, результаты проверок и ограничения.
Полный исторический набор тестов уже падал до переноса: часть архивных материалов
арта отсутствует, часть ожиданий устарела. Тесты не отключены. MySQL-проверка
заблокирована отсутствием рабочего доступа к отдельной тестовой БД.

Оригинальные PixelSurvivor и game-base не изменялись. Commit, push и deployment
не выполнялись.
